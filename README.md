# Лабораторная работа
Расчет числа Нуссельта для пакета труб

## Автор
Бакланова Ляна (Вариант 1)

## Цель
Освоение базового синтаксиса C++ и математических вычислений на примере расчета числа Нуссельта для пакета труб при поперечном обтекании.

## Описание
Программа вычисляет число Нуссельта и параметр Δ для пакета труб, расположенных в шахматном порядке, по заданным формулам для различных значений продольного шага.

## Исходные данные
Число Рейнольдса: Re = 2*10**4
Диаметр труб: d = 25.4 мм
Поперечный шаг: S1 = 60 мм
Продольные шаги: S2 = 30, 50, 65, 75, 80 мм

## Ожидаемые результаты
Программа выводит таблицу значений числа Нуссельта и параметра Δ для каждого продольного шага:

S2 (мм)    Nu         Δ
30.000     134.090    2.030
50.000     ...        ...
65.000     ...        ...
75.000     ...        ...
80.000     102.790    0.570
